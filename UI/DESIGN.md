# Design System

## Brand & Style
The Modern Fidelity design system embraces a clean, professional, and reliable corporate aesthetic. Built with Inter typography across all levels, it ensures high legibility and a contemporary digital feel.

## Colors
The color system utilizes a light color mode featuring a muted primary tone (`#dde3ea`) and a vibrant secondary accent (`#a7fff2`), optimized for clean, professional interfaces.

## Typography
The system uses **Inter** for all headline, body, and label text styles, providing a uniform, crisp geometric aesthetic across all screen sizes.

## Layout & Spacing
A fluid grid layout supported by consistent spacing tokens maintains comfortable breathing room and structure across form factors.

## Elevation & Depth
Subtle tonal layers and ambient shadows define interface depth and hierarchy.

## Shapes
A roundedness level of `2` provides friendly yet professional curved corners across all interactive components.

## Components
Buttons, cards, inputs, and other UI elements consistently reflect the system's typography, roundedness, and color palette.
